# Technology Stack

## Student Mobile
- React Native
- TypeScript
- React Navigation
- React Query/TanStack Query
- Secure local storage
- Push notification support

- App Router
- TypeScript
- MUI
- React Hook Form
- TanStack Query where appropriate

- Express.js
- TypeScript
- Mongoose
- MongoDB Atlas
- JWT
- Argon2
- Joi
- Helmet
- CORS
- Rate limiting
- Winston
- Swagger/OpenAPI
- Jest
- Supertest

## AI
- AI Provider abstraction
- Ollama/local models
- OpenAI
- Gemini
- Claude
- Embedding provider abstraction
- RAG/retrieval layer

## Principles
Avoid Redis, S3, Kubernetes and dedicated microservices in V1 unless actual scale requires them.
