# Student Mobile App

> **Product:** ArivuVazhi (அறிவுவழி) — AI-powered government exam preparation platform

## Stack
React Native + TypeScript

## Main Navigation
- Home
- Practice
- Mock
- AI Coach
- Profile

## Home
Show:
- preparation progress
- streak
- today's plan
- revision due
- next action

## Practice
- topic selection
- adaptive practice
- immediate answer feedback
- explanation
- bookmark/report

## Mock
- test instructions
- timer
- question navigation
- submit
- results

## AI Coach
Conversational interface for:
- explanations
- study planning
- mistake analysis
- revision
- exam-related questions

## UX Rule
The student should not need to understand AI models, providers, RAG or routing.
