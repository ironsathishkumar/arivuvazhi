# Product Requirements

> **Product:** ArivuVazhi (அறிவுவழி) — AI-powered government exam preparation platform

## User Roles
- Super Admin
- Admin
- Content Manager
- AI Manager
- Student

## Student Requirements
1. Register/login.
2. Select target exam.
3. Set target date and study availability.
4. Complete initial assessment.
5. View personalized daily plan.
6. Practice questions.
7. Take mock tests.
8. Review answers and explanations.
9. Maintain a mistake book.
10. Complete scheduled revisions.
11. Ask AI Coach questions.
12. View progress and preparation metrics.
13. Receive notifications/reminders.

## Admin Requirements
1. Manage exams, subjects, topics and exam patterns.
2. Manage questions and question lifecycle.
3. Upload and manage knowledge documents.
4. Review AI-generated questions.
5. Configure AI providers and models.
6. Configure task-to-model routing.
7. Review AI evaluations and failures.
8. View student performance.
9. View AI usage and cost.
10. Manage roles and permissions.
11. View audit logs.

## AI Requirements
- AI provider abstraction
- Local model support
- External provider support
- RAG
- Structured generation
- Validation
- Fallback models
- Prompt versioning
- AI audit logs
- Evaluation datasets
- Cost tracking

## UX Requirements
- Minimal navigation
- Clear next action
- Mobile-first student experience
- Avoid exposing technical AI complexity to students
- Progress should be understandable without requiring interpretation
