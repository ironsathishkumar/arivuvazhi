# Feature Requirements

> **Product:** ArivuVazhi (அறிவுவழி) — AI-powered government exam preparation platform

## MVP
- Authentication
- Exam configuration
- Subjects/topics
- Question bank
- Practice sessions
- Mock tests
- Scoring
- Mistake book
- Revision schedule
- Student dashboard
- AI Tutor
- RAG knowledge base
- AI question generation with review
- Basic performance analytics
- Admin portal
- AI configuration
- AI usage logging

## Phase 2
- Adaptive learning
- AI daily planner
- Advanced mistake classification
- Confidence/progress index
- Current affairs
- Advanced analytics
- Notifications

## Phase 3
- Voice tutor
- Multi-model collective validation
- More exam families
- Advanced offline support
- Mentor features

## Functional Priority
P0 = required for first usable product
P1 = important after MVP
P2 = future enhancement
